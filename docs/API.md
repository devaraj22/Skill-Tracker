# API reference

Interactive, always-accurate OpenAPI docs: `http://localhost:8000/docs` (generated by FastAPI). Base path: `/api/v1`.

**Auth model:** `POST /auth/login` or `/auth/register` sets an HttpOnly `access_token` cookie and a readable `csrf_token` cookie. Every non-GET request must send `X-CSRF-Token: <csrf_token cookie>`.

**Conventions:** 201 on create, 204 on delete, 401 unauthenticated, 403 wrong role / deactivated / CSRF, 404 missing *or not yours*, 409 conflict (duplicate), 422 validation (`{"detail": "Validation failed", "errors": [{loc,msg,type}]}`; submitted values are never echoed). Lists return `{items,total,page,page_size}` with `page` / `page_size` (max 100), `sort`, `order`.

## Documented rules

**Certificate status.** New = `pending`. Only an administrator can set `verified`/`rejected`, which records reviewer and time. If a student changes the title, issuer, dates, credential link or evidence file of a reviewed certificate, it returns to `pending`. Only `verified` **and** `is_public` certificates appear on a portfolio.

**Learning-goal status.** `status=completed` forces progress 100; progress 100 sets completed; 0 < progress < 100 sets in_progress (reopening a completed goal); progress 0 keeps the chosen status. A goal is *overdue* when it has a past target date and is not completed.

**Profile completion.** Percent of 10 fields filled: full name, register number, department, year, avatar, bio, GitHub, LinkedIn, resume, portfolio username.

**Placement preparation percentage.** `percent = score / max_score x 100` per assessment. Each category's value is its most recent assessment (by date, then creation time). The overall figure is the mean of category values over **only categories that have data**; missing categories are listed and never counted as zero. It is a preparation indicator, not a probability of placement or a validated employability measure. Admin analytics show the mean of *all* assessments per category.

**Dashboard counts.** `certificates_verified` is a subset of `certificates_submitted`; all counts are SQL aggregates over the student's own rows.

**CSV export.** Name, register number, department, year, status and per-student counts. No emails. Cells beginning with `= + - @` (or tab/CR/LF) are prefixed with `'`.
